# Athar AI — Milestone Plan (v4)

## PHASE −1 — WIZARD OF OZ (GATE) · 0 dev-days of product · ~1 calendar week
Learn whether an agency will pay **before building anything.** No repo, auth, UI, or transcription.
- **Day 1–2:** voice spike exactly as specced — throwaway ~50-line script, no repo. Hand-write the DNA-extraction + draft prompts on your 5 real posts + 1 transcript; iterate to 5 drafts; **blind-test to 3 Gulf agency owners** ("does this sound like the person who wrote the source posts?").
- **Day 3–5:** hand-deliver **~10 drafts to 2 real Gulf agencies** (one client brand each), generated by **you running the prompts manually.** **First delivery uses PASTED TEXT POSTS only — no audio**, so the transcription bake-off is *not* on this path.
- **Day 6:** ask for money — **~$200/mo for ~20 drafts/week in their client's voice.**
- **GATE:** **0 agencies pay → STOP; do not build.** 1+ pays → proceed to M0.
- **Deliverable:** `docs/PHASE_MINUS_1.md` — the 3 blind verdicts, the 2 concierge outcomes, and the paying/not-paying result. **This document gates M0.**

> **Everything below (M0–M5) is CONDITIONAL on Phase −1 producing a paying agency.** If Phase −1 fails the gate, none of it is built. Dates in the calendar table are therefore contingent and shifted +1 week for Phase −1.

## M0 — Foundations, legal pages, lead-time kickoffs · ~5 dev-days · *conditional on Phase −1*
Day-1 parallel: keep the paying Phase −1 agencies warm; you record the **10 dialect audio samples** (feeds M0.5). Deliverables: git + `.gitignore` (`.env*`) + pre-commit secret scan on the first commit; Next.js 15+TS scaffold; `styles/tokens.css`; `next/font`; `next-intl` `/ar`(RTL)+`/en`(LTR); `messages/ar.json` extracted from `design-reference/`; CI; copy handoff → `design-reference/`; static `/terms`, `/privacy`, `/refund`; **`lib/ai/models.ts`** (single source of truth for exact model ID strings). No Paddle, no marketing/pricing page. Register Athar domain.

## M0.5 — Dual bake-off: transcription + retrieval (ADRs) · ~5 dev-days · gated on your 10 samples
Transcription (B1) → `docs/EVAL_TRANSCRIPTION.md`; Arabic retrieval/embeddings (C4): 20 queries × 3-source corpus, recall@5 across ≥2 models → `docs/EVAL_RETRIEVAL.md`; **pin `vector(N)` only after.** Adapters swap via env.

## M1 — Vertical slice: ONE screen (Studio) through real auth+DB · ~10 dev-days
Studio end-to-end on the real spine (thin auth + `brands`/`dna_versions`/`drafts`) using Phase −1's surviving prompts → real DNA v0 → draft in the UI, `/ar`+`/en`. Proves the whole spine before widening.

## M2 — Widen: 3 screens + full auth + cold-start + tenancy · ~12 dev-days
Pixel-perfect Ingest/Import, Analysis, Content DNA on the real stack; full auth (email + Google + LinkedIn) + Resend; cold-start (voice interview OR paste/URL → DNA v0 <5 min); `organizations→memberships→brands`; **`db.forOrg()` façade + lint + RLS**; PostHog funnel; **CI tenancy test** (2-brand org).

## M3 — Data layer, retrieval, credits, eval harness · ~12 dev-days
Schema + reversible migrations + seed; pgvector + Arabic chunking + hybrid retrieval (cited); `credit_ledger` append-only + pre-flight estimate; `generations` logging; Inngest jobs (retry/DLQ/timeout/cancel) + `jobs` table; prompt registry + golden-set eval gating CI; soft-delete + Storage cascade; `sources.status` machine with retry/terminal-failure.

## M4 — AI pipeline complete (hardened) · ~13 dev-days
Full ingest→analyze→DNA→ideas→Studio with retrieval on every content-read; model tiering (via `lib/ai/models.ts`) + caching + Batch; dialect module v1; guardrails v1 (banned-list + one reviewer pass, blocks export); DNA-match composite score (or removed); injection-safe (delimited data + structured output + no tools) + SSRF-safe URL ingestion; MIME sniff + size caps + quarantine + short-expiry signed URLs. Golden-set includes the injection case; SSRF case passes.

## M5 — Export-first, observability, polish, ship · ~8 dev-days
Export-first (clipboard + composer deep links + asset bundle); honest internal metrics only; Sentry + structured logs; `docs/ADMIN_RUNBOOK.md`; full `en` pass + numeral/date QA; a11y both directions; Playwright e2e (auth + core workflow) + unit (credit math, tenancy, plan gating); deploy.

## Post-MVP (after Design Partners validate WTP)
Paddle + webhooks + checkout + marketing/pricing page; self-serve agency tier; brand switcher/seats/roles/client-review links; Calendar/Approvals/Analytics/standalone Ideas; dialect-authenticity reviewer; Saudi gateway; real publishing + platform analytics; admin UI; feedback→DNA loop (schema-ready).

## Contractor acceptance precondition (fix C-contractor)
**Before any contractor starts the ~43 commodity dev-days, the acceptance harness must already exist and be authored by you/me:** the **CI tenancy test, the prompt-injection eval case, the SSRF eval case, and the credit-math unit tests.** Contractor acceptance is **mechanical — CI green — never your judgment of their code.** This means those four artifacts are pulled to the front of their milestones (author the test before delegating the implementation). Encoded here and in `RISKS.md`.
