# الوثائق — أيّها يصف اليوم، وأيّها سجلّ

بعض ما في هذا المجلد كُتب قبل أن يُبنى المنتج. وثيقة قديمة تُقرأ كمرجع، ومرجع
خاطئ أسوأ من لا مرجع — فكل ملف هنا إمّا يصف الكود اليوم، أو يحمل في أوّله بانر
يقول إنه سجلّ تاريخي. هذا الفهرس هو الطريق القصير.

## يصف الكود اليوم

| الملف | يجيب عن |
|---|---|
| `ARCHITECTURE.md` | ما هو مبنيّ فعلًا، وكيف يعمل: العزل، المقاعد، الحلقة المغلقة، روابط المراجعة، قائمة النشر |
| `DECISIONS.md` | القرارات المعمارية وأسبابها وعواقبها (ADR-000 … ADR-013) — محدَّثة مع كل قرار |
| `LAUNCH_READINESS.md` | ما الذي يمنع أول عميل يدفع بنفسه، ومن يملك كل بند |
| `ADMIN_RUNBOOK.md` | التشغيل: الهجرات، النشر، النسخ الاحتياطي واستعادته، الأخطاء المعروفة |
| `RLS.md` | عزل الصفوف: ما يفعله، ولماذا هو خامل، وكيف تُفعّله وتتراجع |

| `PUBLISHING.md` | النشر الفعلي على المنصّات، وما تحتاجه كل منصّة |
| `MONITORING.md` | الصحة والسجلات وSentry والتنبيهات |
| `DEPENDENCIES.md` | التبعيات والثغرات المعروفة وأسباب ما لم يُرقَّ |
| `NOT_BUILDING.md` | ما لا نبنيه عمدًا، ولماذا، وما الذي يغيّر القرار |

## القاعدة

وثيقة تصف ميزة مبنيّة على أنها «مؤجّلة» ليست قديمة فحسب، بل مُضلِّلة — تُقرأ
كسلطة. إن صادفت واحدة، أصلحها أو ضع عليها تاريخًا. `NOT_BUILDING.md` كان أسوأ
مثال على ذلك: ظلّ يعدّد المقاعد وروابط المراجعة والنشر الفعلي والحلقة المغلقة
كأشياء لن تُبنى، بعد شهر من بنائها كلها.
