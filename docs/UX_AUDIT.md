## 🔴 أخطاء منطقية حقيقية (يُنصح بإصلاحها أولًا — كلفة منخفضة)
1. **Approvals:** `تحرير` و`رفض` ينفّذان نفس الاستدعاء `setDraftStatus("needs_edit")`.
2. **Onboarding 1:** زر `back` مجرّد `<span>` غير تفاعلي.
3. **Onboarding 3:** خطوة `suggest` تبقى `pending` عند اكتمال العملية (تبدو كأنها فشلت).
4. **Ideas:** فلتر «رائجة» فارغ دائمًا (لا يُنتَج bucket=trending)؛ و`angle` المُولّد لا يُعرض؛ و«اكتب» لا يمرّر سياق الفكرة.
5. **DNA:** حقل `summary` مُخزَّن ولا يُعرض.
6. **Analytics:** شرائح المدى الزمني بلا `onClick`.

## 🟢 مكاسب سريعة عالية الأثر (البنية جاهزة، الكلفة منخفضة)
- إعادة استخدام الأفكار المستخرجة من التحليل (`saveIdeas`+`sourceId` موجودة بالفاصادة، غير مستدعاة).
- حذف/إدارة المصادر (`deletedAt` موجود بالمخطط).
- تمرير السياق بين الشاشات (`?idea=`/`?source=`) لربط الفكرة→التحليل→الاستوديو.
- «لماذا هذا السكور؟» (كشف منطق `score.ts` الشفّاف أصلًا).
- عرض `dna.summary` و`idea.angle` (حقول موجودة ومهدرة).

## 🧵 خيوط متكرّرة عبر كل الشاشات
- **حالة تركيز موحّدة** (`:focus-visible`) — كل الحقول/الشرائح `outline:none` بلا بديل.
- **دلالة الاختيار للقارئ الصوتي** (`aria-pressed`/`role=switch`).
- **صدق التغذية الراجعة** — إزالة الأزرار الزخرفية والتقدّم الوهمي والوعود غير الموصولة.
- **Skeletons + Undo + autosave** — دفعة واحدة ترفع الإحساس بالجودة عبر المنتج.
